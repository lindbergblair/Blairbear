# Paris → Bordeaux travel app

A static, offline-capable web app: pick where you start in Paris and where you're headed in Bordeaux,
and get a step-by-step itinerary (metro/RER to Montparnasse, TGV/OUIGO to Bordeaux Saint-Jean, tram onward).

Run: `python3 -m http.server` and open http://localhost:8000.

**Data is representative, not live.** Edit `data.js` to update trains and routes, and confirm real times
on SNCF Connect, TBM (Bordeaux) and RATP before travelling.
